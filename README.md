# NewsDigest

Тематичні дайджести з Telegram: планове читання каналів звичайним акаунтом,
AI-узагальнення, публікація всіх унікальних придатних новин у потрібні канали.
Довгий випуск виходить послідовними пронумерованими частинами.

**Стан на 2026-11-11:** підготовлено документацію; застосунок ще не реалізований.
Наявний `main.py` — початковий шаблон PyCharm, а не точка запуску NewsDigest.
