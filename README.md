# NewsDigest

Тематичні дайджести з Telegram-каналів і сайтів: планове читання джерел звичайним
акаунтом, AI-узагальнення (`gpt-5.6-sol`), публікація всіх унікальних новин у ваші
канали в хронологічному порядку. Кожен цільовий канал описується в JSON-конфігу
(`target_channels`). Довгий випуск виходить пронумерованими частинами.

**Стан на 2026-11-11:** підготовлено документацію; застосунок ще не реалізований.
Наявний `main.py` — початковий шаблон PyCharm, а не точка запуску NewsDigest.
